  TROUBLESHOOTING:
════════════════════════════════════════════════════════════════════

If the app won't start:
  1. Make sure Node.js is installed (npm command works)
  2. Double-click RUN_APP.cmd again
  3. Wait a few moments - first launch takes longer
  4. Check the command window for error messages

Port 3000 already in use?
  - Try closing other apps
  - Or run the built app (see DESKTOP_APP_GUIDE.md)
